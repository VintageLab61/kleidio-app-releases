# Kleidio App · Releases

Hier liegen die Installationspakete der Kleidio-App (Windows, später Mac). Die App holt sich neue Versionen von hier automatisch im Hintergrund, du musst nichts neu herunterladen.

- Erste Installation: neueste Version unter **Releases** laden und installieren.
- Danach: die App prüft alle paar Stunden selbst, lädt still und installiert beim nächsten Beenden (oder sofort über Hilfe → „Neu starten und aktualisieren“).

Der Quellcode der App liegt nicht hier. Fragen und Feedback bitte direkt in der App über Hilfe → „Feedback senden“.
